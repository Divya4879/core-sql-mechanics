# Core SQL Mechanics

A structured SQL learning repository focused on understanding query mechanics, practicing problem-solving, and building a reusable reference for common SQL patterns.

The repository combines foundational exercises, intermediate practice, advanced problem-solving notes, and selected LeetCode problems that required additional work or review.

## Part 1: Learning Progression

The repository is organized into three main learning sections, followed by a separate collection of additional practice problems.

| Section | Directory | Purpose |
|---|---|---|
| Foundations | `sql_foundations/` | Establish core SQL concepts and database operations |
| Intermediate | `sql_intermediate/` | Develop confidence with more involved queries and analytical tasks |
| Advanced | `sql_advanced/` | Consolidate challenging concepts and problem-solving patterns |
| Random Drills | `random_drills/` | Revisit selected problems outside the SQL 50 study plan |

## Part 6: Recurring SQL Mechanics

Across the repository, the emphasis is on developing a practical understanding of how SQL queries behave.

Key areas of practice include:

- **Query construction:** translating problem requirements into precise SQL statements.
- **Relational reasoning:** understanding table relationships, joins, and missing values.
- **Aggregation:** choosing appropriate grouping and aggregate operations.
- **Query logic:** reasoning about conditions, subqueries, and intermediate results.
- **Analytical querying:** applying ranking and window-based techniques where appropriate.
- **Validation:** checking edge cases and understanding why a query succeeds or fails.

The objective is not simply to collect accepted solutions, but to build familiarity with reusable patterns and improve independent problem-solving.
